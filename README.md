InstaBusiness Connector App
This is an Android application built using Android Studio that integrates Instagram Business features directly into the app. The project also utilizes Lottie animations for a modern and engaging user experience.

📱 Features
🔗 Connect Instagram Business Account

🧾 View and manage Instagram Business Product Post

🎞️ Smooth and interactive UI with Lottie animations


📊 Display business insights and analytics 

🛠️ Tech Stack
Language: Java

IDE: Android Studio

Instagram Graph API 

Lottie (for animations)


🎨 Lottie Animations
Lottie files are used to enhance the user interface with engaging animations.
Animations are stored in the assets folder and used with the LottieAnimationView widget.
